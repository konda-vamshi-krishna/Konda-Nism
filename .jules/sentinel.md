## 2023-11-07 - XSS Vulnerability in File Staging Area
**Vulnerability:** Found an XSS vulnerability in `js/app.js` where user-uploaded file paths and file names were being concatenated directly into `innerHTML` strings during the validation and staging display flow without sanitization. An attacker could inject malicious scripts by uploading a file with a crafted filename (e.g. `"><script>alert(1)</script>.json`).
**Learning:** File metadata originating from client drops or file selection dialogs must be treated as untrusted user input, even when processed entirely client-side. The codebase relies heavily on Vanilla JS DOM generation via `innerHTML` template literals, which is inherently risky if any variables aren't escaped.
**Prevention:** Always use the `escapeHTML` helper function before interpolating dynamic data into `innerHTML` strings. Alternatively, use `textContent` to safely assign dynamic text content when possible, or generate DOM elements programmatically via `document.createElement`.
