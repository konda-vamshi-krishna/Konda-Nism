## 2024-05-18 - [Accessibility: Screen reader only class]
**Learning:** This codebase does not currently contain an `.sr-only` class to hide elements visually while exposing them to screen readers, which is essential for adding accessible descriptions/labels.
**Action:** Add `.sr-only` utility to `css/style.css` and use it to add visually hidden instructions to interactive elements (like the flashcard).
